Mercury is written in C++, which isn't terribly unusual for a high-level bytecode language. While knowing the exact workings of mercury's backend code isn't needed to use the language, understanding how the language works can give some really good insight into why it behaves the way it does.

this chapter will also prove to be useful for anyone who wants to contribute to the language, or write their own extensions for it.

most of the code in the chapter will be C++, and not mercury. though you will be able to tell which is which by looking at it;
