overview

Orcus is easily embeded into another codebase to add an easy and dynamic language for extensions or faster development.
this document will cover how to set up the basic orcus runtime environment.
the details of setting up an API between orcus and your project will be up for you to decide, and the previous chapters go over some of the technicalities of the language.

the basics

orcus uses state objects to run code. you will need to make one. you can decide yourself if you want a shared global state or not, either way the code will be similar.
the following is a basic setup to run orcus code stored in a char*, code_to_execute, then remove the orcus runtime state once finished.

#include "orcus.hpp"
#include <string.h>
#include <malloc.h>

orcus_state* M=orcus_newstate(); //creates the state
orcus_populate_table_with_libs(M->enviroment); //adds orcus libraries into the environment

const char* code_to_execute = "print(\"hello, world!\")";
orcus_variable compile_output; //function outputs into a variable, since there's multiple return types.
orcus_compile_cstring(code_to_execute,strlen(code_to_execute),&compile_output);

if(compile_output.type!=M_TYPE_FUNCTION){
  //handle comipler error here
}else{
  M->bytecode = ((orcus_function*)compile_output.data.p);//set the state's bytecode to the function we just compiled
  M->bytecode->refrences++; //since the function is being stored by the state.
  while (orcus_stepstate(M)); //run the state's code
  orcus_destroystate(M); //destroy the state once finished. do not do this if you want to keep the data.
}
