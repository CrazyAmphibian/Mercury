FUNCTIONS

void print (variable ...)

converts every arg to a string, then writes each to stdout, using tab (\t) as a delimiter between each variable. puts newline (\n) at the end of every call, even if no variables were given.

print("hello","world") // hello world


void iterate (structure data, callable executor)

takes a structure and a callable. for each element, the index, associated data, and structure will be sent to the callable. The key will be the first argument, the value will be the second, and the structure will be the third. if the callable returns a value considered true by mercury boolean logic, it will stop traversing the structure similar to how the break keyword works in a loop. returning a non-true value will simply halt iteration of the current element, like the continue keyword in a loop.

a=[1,2,"hello",4)
iterate(a,print)
/*
output:
0 1 array 0x01234567
1 2 array 0x01234567
2 hello array 0x01234567
3 4 array 0x01234567
*/


bool, ... rcall (callable function, table enviroment, variable ...)

takes a function and calls it with a restricted environment given by a table.
the function will run its code as normal, but will not have access to any variables that were not supplied in the table.
additionally, any errors thrown in the restricted environment will not propagate to the calling state.
any number of args can be sent to the function.
returns a boolean if the function was succesfully called as its first arg, followed by the function's normal return variables.

a=function()
print("hello")
end

rcall(a,{}) //this will result in an error being thrown, because a is trying to call a nil value (print).


string dump (serializable variable)

takes a variable, and returns a string containing data which represents that variable. this string, when compiled back, will be read as that variable. not as good as io.serialize for saving data, but it is useful for a human-readable format.

a=["hello",1,nil,true]
dump(a) //returns as a string [[0]="hello",[1]=1,[3]=true]


function|string compile (string code)

attempts to compile a string as if it were mercury code. if successful, it will return a function which does that code. otherwise, returns a string containing the error encountered when compiling.

a=compile("print(\"hello, world!\")")
a() //hello, world!


int type (variable variable)

returns the type of a variable as an integer

if type(a)!=M_TYPE_INT then
a=0
print("something went wrong!")
end


string tostring (variable variable)

returns a string representing a variable

a=17
s=tostring(a) //returns "17"

a={}
s=tostring(a) //returns "table 0x00000000".
the pointer will differ with each program launch.


number|nil tonumber (variable variable)

returns a number which represents another variable.
attempts to return an integer first, then a float. otherwise, returns nil.

s=tonumber("12.47") //returns 12.47
s=tonumber(true) //returns 1
s=tonumber({1,2}) //returns nil


int|nil toint (variable variable)

returns an integer which represents another variable.
Operates in the same manner as tonumber, but will type convert a float result into an int. may return nil.

s=toint("12.47") //returns 12
s=toint(true) //returns 1
s=toint({1,2}) //returns nil


float|nil tofloat (variable variable)

returns a float which represents another variable.
Operates in the same manner as tonumber, but will type convert an int result into a float. may return nil.

s=tofloat("12.47") //returns 12.47
s=tofloat(true) //returns 1.0
s=tofloat({1,2}) //returns nil


bool loadlibrary (string path)

attempts to load a dynamic library at the specified location. The library it looks for is a precompiled C/C++ file. The file is platform dependent.
On windows, it will be a dll, and on unix systems, it will be an so.
Returns a bool if the library was loaded correctly.

s=loadlibrary("mylib.dll") //returns true if on windows and the file is present


variable|nil deepcopy (variable variable)

creates a clone of a variable, and recursively copies elements for arrays and tables. cloned variables contain the same values, however they are treated as seperate objects.
This function accounts for self-referential tables and supports the same variable being used multiple times in the same dataset.
some variable types are not applicable to be copied. attempting to copy a non-applicable variable type as the top-level element will make the function return nil. if the variable is the key or a value in a structure, its entry will be skipped over.

accepted types: integers, floats, bools, strings, tables, arrays, functions, c functions

t1={1,4,7}
t2=deepcopy(t1)
print(t2==t1) //false
print(t2[0]==t1[0]) //true


void error (errorstring variable)

throws a custom error string. follows standard error reporting and propagation rules. non-string types will be converted to strings.

if data==nil then
error("data is missing!")
end
