FUNCTIONS

table copy ( table table )

creates a new table which contains the same values as the supplied table.

a={"hello",1,nil,true}
b=table.copy(a)
print(a==b) //false


void flush ( table table )

removes all nil values from a table's storage, shifting around elements to fill in the space, and will free up memory.
if used on an environmental table (such as _G or _ENV), implicit lexical scoping may potentially break, as the variables will no longer be seen as defined.

a=function(n) table.flush(_ENV) print(n) end

n=100
a(10) //prints 10, as the flush call does nothing.
a(nil) //prints 100, as the variable n is nil, and becomes undefined. the print call will search upward for a variable named n, since it is not given an explicit location with scope keywords.


array, int getkeys ( table table )

returns an array of all keys in the table, as well as the number of keys.
array is not guaranteed to be in any particular order. though practically speaki ng, they will be in order of first type number, then by order of insertion.
array elements will be in the same pair order as elements returned by getvalues.
includes the nil key, as well as any keys associated with a nil value.

a={"hello"=1,3=6,false=nil}
table.getkeys(a) //returns [3,false,"hello"], 3


array, int getvalues ( table table )

returns an array of all values in the table, as well as the number of values.
array is not guaranteed to be in any particular order. though practically speaking, they will be in order of first type number, then by order of insertion.
array elements will be in the same pair order as elements returned by getkeys.
includes the nil key, as well as any nil values.

a={"hello"=1,3=6,false=nil}
table.getvalues(a) //returns [6,nil,1], 3


bool, variable|nil haskey ( table table, variable key )

returns if a table has a value associated with the provided key, even if that value is nil.
returns a boolean if it exists, as well as the value associated with the key or nil if it wasn't found.

global a=nil
table.haskey(_G,"a") //returns true, nil


bool, variable|nil hasvalue ( table table, variable value )

returns if a table has a key associated with the provided value, even if that key or value is nil.
returns a boolean if it exists, as well as the value associated with the key or nil if it wasn't found.
only returns the first found occurrence of the variable.

global a=nil
table.hasvalue(_G,nil) //returns true, "a"
global b=nil
table.hasvalue(_G,nil) //still returns true, "a" as a will (probably) be found first


array, int keyswithvalue ( table table, variable value )

returns an array of keys (including nil) from the supplied table that are associated with the provided value, as well as how many keys had that value.
returns an empty array if none were found.
rray is not guaranteed to be in any particular order. though practically speaking, they will be in order of first type number, then by order of insertion.

a={1=20, 3=2, "test"=20, true=5, 15.2=0, inf=20}
table.keyswithvalue(a,20) //returns [1,"test",inf], 3
