CONSTANTS

Variable Type Value Desc

FUNCTIONS

void flush ( array array )

removes all nil entries from an array, so that all values spanning 0 to the maximum have a value

a=["hello",1,nil,true]
array.flush(a) //a is now ["hello",1,true]


array copy ( array array )

returns a new array containing the same values as the old one, but as a seperate object.

a=["hello",1,nil,true]
b=array.copy(a)
print(a==b) //false


int insert ( array array, variable element, [int index=end] )

adds element to array.
if index is specified, the new element will be at that location, shifting all other elements forward to make space.
if not provided, it will instead add the element to the end of the array.
Returns the index that the variable was placed at.

a=["hello",1,nil,true]
b=array.copy(a)
print(a==b) //false


int remove ( array array, int index )

removes an element from an array.
shifts all other elements backwards to fill in the removed element's space.
if a return arg is specified, the returns the removed element, otherwise it is discarded.

a=["hello",1,true]
array.remove(a,1) //array is now ["hello",true]


void swap ( array array, int index1, int index2 )

swaps the positions of 2 variables in an array.
if a position does not exist, nil will be used instead.

a=["hello",1,true]
array.swap(a,0,2) //array is now [true,1,"hello"]


void sort ( array array, function|int sorting_function )

takes an array, and runs a sorting function through it.
mercury functions take 2 values and should return 1, 0, or -1.
one of the constant array library functions can be used as well

this function is not thread safe.

a=[7,1,3]
array.sort(a,array.SORTING_GREATER_TO_LESSER) //array is now [7,3,1]


string concat ( array array, string separator )

returns a string formed from each element in an array, from 0 to the end, and adds the separator string between each element.
automatically runs tostring on each element.

a=["hello",1,true]
array.concat(a,",") //returns "hello,1,true"
