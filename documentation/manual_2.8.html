this is a complete list of every function or inline provided in orcus.hpp, as well as how they operate.

string functions

orcus_string* orcus_cstring_to_mstring(const char* const restrict str, const orcus_int size);

creates a new orcus string based on the data from a character array.
the resulting orcus_string* will use a unique pointer for its char*, seperate from the provided one.
returns nullptr on a memory allocation failure.

orcus_string* orcus_cstring_const_to_mstring(const char* const restrict str, const orcus_int size);

creates a new orcus string marked as constant using a supplied character array.
the resulting orcus_string* will use the pointer provided, but will never modify or free the pointer or assocaited data.
returns nullptr on a memory allocation failure.

orcus_string* orcus_cstring_promote_to_mstring(char* const restrict str, const orcus_int size);

creates a new orcus string using a supplied character array.
the resulting orcus_string* will use the pointer provided, and the orcus runtime will manage and possibly modify the pointer data, as well as freeing or reallocating.
returns nullptr on a memory allocation failure.

char* orcus_mstring_to_cstring(const orcus_string* const restrict str)

creates a new character array, based on the supplied orcus string.
the resulting array will be null-terminated, but is not guaranteed to only have null occur at the end.
returns nullptr on a memory allocation failure.

orcus_string* orcus_copystring(const orcus_string* const restrict str)

creates a new orcus_string which has the same data as the supplied.
if the supplied string is marked as constant, the pointer will be copied.
otherwise, this will create a new pointer and copy the data from the original
returns nullptr on a memory allocation failure.

orcus_string* orcus_mstrings_concat(const orcus_string* const str1, const orcus_string* const str2)

creates a new orcus_string whose data is the concatenation of both input strings, with the first arg being the first portion of the resulting string. returns nullptr on a memory allocation failure.

bool orcus_mstrings_append(orcus_string* const basestr, const orcus_string* const appstr)

modifies the first arg string with the second arg's string affixed to the end.
if the first arg is a constant string, a new pointer will be allocated to the string, and it will be unmarked as constant.
returns false on a memory allocation failure.

bool orcus_mstring_addchars(orcus_string* const ORCUS_CPP_restrict str, const char* const chars, orcus_int len=1)

modifies the first arg string with the supplied character array appended to it
if the first arg is a constant string, a new pointer will be allocated to the string, and it will be unmarked as constant.
returns false on a memory allocation failure.

orcus_string* orcus_mstring_substring(orcus_string* str, orcus_int start, orcus_int end)

creates a new string composed from the supplied string. the integer args are an offset from the start of the string (0 indexed)
may return a zero length (empty) string
returns nullptr on a memory allocation failure.

void orcus_mstring_delete(orcus_string* const restrict str)

frees the supplied orcus_string, regardless of reference count.
if the pointer is not marked as constant, it will be freed.

inline bool orcus_mstrings_equal(const orcus_string* const str1, const orcus_string* const str2)

returns a bool if the supplied orcus strings have the same data.

inline bool orcus_mstring_equal_cstring(const orcus_string* const mstr, const char* const cstr)

returns a bool if the supplied orcus string has the same data as the supplied null-terminated character array.

table functions

orcus_table* orcus_newtable()

creates a new, empty table object returns nullptr on a memory allocation failure.

orcus_int orcus_tablehaskey(const orcus_table* const table, const orcus_variable* const key)

searches a table for the supplied key. if found, returns the index in the subtable where it was found.
if not, returns -1.

bool orcus_getkey(const orcus_table* const table, orcus_variable* const key, orcus_variable* out)

sets the data at the variable pointer out to the value stored by the supplied key. if not found, returns false, and sets out to nil.

orcus_int orcus_setkey(orcus_table* const table, orcus_variable* const key, const orcus_variable* const value)

sets a key in the table, and returns the index in the subtable. on allocation failiure, returns -1.
both the supplied key and value will have their refrence count incremented and will be stored in the table.
the existing stored data will be unrefrenced, and position overwritten, potentially freeing the data.

bool orcus_tables_equal(const orcus_table* const table1, const orcus_table* const table2)

evaluates every key in a table against another table. if every value is equal, returns true. otherwise, false

bool orcus_table_get_cstring_keyvalue(const orcus_table* const table, const char* const key, orcus_variable* out)

sets the data at the variable pointer out to the value stored by the supplied key. if not found, returns false, and sets out to nil. Takes a null-terminated character array aas a key instead of a variable.

orcus_int orcus_table_set_cstring_keyvalue(orcus_table* const table, const char* const key, const orcus_variable* const value)

sets a key in the table, and returns the index in the subtable. on allocation failiure, returns -1.
both the value will have its refrence count incremented and will be stored in the table.
the existing stored data will be unrefrenced, and position overwritten, potentially freeing the data.
the supplied character array must point to a constant point in memory, and should not be freed, and be null terminated

orcus_int orcus_table_has_cstring_key(const orcus_table* const table, const char* const key)

searches a table for the supplied key. if found, returns the index in the subtable where it was found.
if not, returns -1.
the supplied character array must be null terminated

void orcus_prepare_table_for_state(orcus_table* table,orcus_state* M)

sets the values _G and _ENV given a state and its environment table.
additionally, sets the environmental flag of the table.

void orcus_cleartable(const orcus_table* const table)

goes through all stored variables in the stored table, and unrefrences, and possibly frees them, then removes them from storage.

void orcus_destroytable(orcus_table* const table)

frees the supplied table. goes through all stored variables, and unrefrences, and possibly frees them.

array functions

orcus_array* orcus_newarray()

creates a new array object.
returns nullptr on failiure.

bool orcus_setarray(orcus_array* const array, const orcus_variable* const var, const orcus_int pos)

sets the array's index to the provided value.
increases the supplied value's reference count.
if the index already stored a value, it will be dereferenced, replaced, and potentially freed.
on success, returns true.

void orcus_getarray(orcus_array* const array, const orcus_int pos, orcus_variable* out)

sets the data at the provided pointer to the value stored in the array at the index.
if the value is not present, nil is set instead.

orcus_int orcus_array_len(const orcus_array* const restrict arr)

returns the index of the array's value with the highest value.
if there are no values, -1 is returned instead.
ignores negative indexes.

void orcus_destroyarray(orcus_array* const restrict arr)

frees the provided array, and dereferences and potentially frees all stored values.

state functions

orcus_state* orcus_newstate(const orcus_state* const parent = nullptr)

creates a new state. if parent is provided, this will set the new state's parent to the provided.
returns nullptr on failure.

bool orcus_stepstate(orcus_state* const restrict M)

executes a single instruction of a state's bytecode.
returns true if there are more instructions to execute.

void orcus_clearstate(orcus_state* const restrict M, bool for_deletion=false)

clears a state into its initial state.
the second arg should not be used, as it is an internal designation

void orcus_destroystate(orcus_state* const restrict M)

frees a state and unreferences or frees all associated data.

void orcus_release_var(orcus_variable* const restrict var)

checks a variable's reference count, and frees the data if it is 0

void orcus_popstack(orcus_state* const restrict M, orcus_variable* out)

sets the data at the pointer out to the provided state's top stack element, and decreases the stack size.
if there is no element on the stack, out is set to nil instead.

void orcus_pullstack(orcus_state* const restrict M, orcus_variable* out)

sets the data at the pointer out to the provided state's bottom stack element, and decreases the stack size then shifts all elements back by 1.
if there is no element on the stack, out is set to nil instead.

void orcus_pushstack(orcus_state* const restrict M, orcus_variable* var)

adds the provided variable onto the top of the provided state's stack.
returns true if this occured successfuly, and false if not.

inline void orcus_discard_top_of_stack(orcus_state* const restrict M)

takes the top variable of the stack of the provided state, and removes it, potentially freeing it.

inline void orcus_peek_stack(const orcus_state* restrict M, orcus_variable* out)

sets the data at the pointer out to the variable on the top of the stack if it exists, nil if not.
does not change the stack size.

inline orcus_state* orcus_get_child_state(orcus_state* const ORCUS_CPP_restrict M)

returns a pointer to a state's child state, used for function calls.
creates the state if none exists.
returns nullptr on failure.

variable functions

orcus_string* orcus_tostring(const orcus_variable* const restrict var)

creates a new string that represents the supplied variable's value.
if the supplied variable is also a string, a new one is still created
returns nullptr on failure

bool orcus_checkbool(const orcus_variable* const restrict var)

interprets the supplied variable as a boolean, and returns the corresponding value.

orcus_int orcus_checkint(const orcus_variable* const restrict var)

interprets the supplied variable as an integer, and returns the corresponding value.

orcus_float orcus_checkfloat(const orcus_variable* const restrict var)

interprets the supplied variable as a floating-point number, and returns the corresponding value.

orcus_float orcus_checkpointer(const orcus_variable* const restrict var)

interprets the supplied variable as a pointer, and returns the corresponding value.
for non pointer types, nullptr is returned.

bool orcus_vars_equal(const orcus_variable* const var1, const orcus_variable* const var2)

evaluates if the two suppplied variables are equal, using orcus equality rules.

inline void orcus_clear_variable(orcus_variable* var)

sets the data at the pointer to nil

inline bool orcus_type_is_complex(const uint8_t type)

returns if the type is complex (referenced)

inline void orcus_increment_variable_refrence_count(const orcus_variable* const restrict var)

increments a variable's reference count

inline void orcus_decrement_variable_refrence_count(const orcus_variable* const restrict var)

decrements a variable's reference count

other functions

bool orcus_register_library(void* data, const char* key, const char* table, uint8_t type=ORCUS_TYPE_CFUNC)

adds data to orcus's global libraries list.
data is a pointer to the data
key is a null-terminated string
table is an optional null terminated string. if supplied with nullptr, will add the library to the table, otherwise, adds it to a sub-table whose key is the supplied string
type is the type of the library. supported types: int, float, bool, c function
returns false if the library failed to be added
not thread safe.

void orcus_populate_table_with_libs(orcus_table* T)

adds all libraries into the supplied table.

orcus_string* orcus_get_bytecode_debug(orcus_function* F)

generates a string representing a function's bytecode
annotates instructions and their bytecode parameters
returns nullptr on failiure

orcus_string* orcus_get_bytecode_rawbinary_debug(orcus_function* F)

generates a string representing a function's bytecode
annotates hex, char, (un)signed int, and opcodes
returns nullptr on failiure

void orcus_debugdumptable(orcus_table* tab, int level = 0)

generates a debug string of a supplied table, and sends it to stdout.
optional level arg is for internal use only.

void orcus_clone_function(orcus_function* in, orcus_function* out)

copies a function's data into a new function. the function object must already exist. on failure, the output function's instruction count will not be the same as the input's

void orcus_clear_function(orcus_function* in)

clears all data associated with a function pointer, but does not free the pointer.
