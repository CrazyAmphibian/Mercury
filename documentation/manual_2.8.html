this is a complete list of every function or inline provided in mercury.hpp, as well as how they operate.

string functions

mercury_string* mercury_cstring_to_mstring(const char* const restrict str, const mercury_int size);

creates a new mercury string based on the data from a character array.
the resulting mercury_string* will use a unique pointer for its char*, seperate from the provided one.
returns nullptr on a memory allocation failure.

mercury_string* mercury_cstring_const_to_mstring(const char* const restrict str, const mercury_int size);

creates a new mercury string marked as constant using a supplied character array.
the resulting mercury_string* will use the pointer provided, but will never modify or free the pointer or assocaited data.
returns nullptr on a memory allocation failure.

mercury_string* mercury_cstring_promote_to_mstring(char* const restrict str, const mercury_int size);

creates a new mercury string using a supplied character array.
the resulting mercury_string* will use the pointer provided, and the mercury runtime will manage and possibly modify the pointer data, as well as freeing or reallocating.
returns nullptr on a memory allocation failure.

char* mercury_mstring_to_cstring(const mercury_string* const restrict str)

creates a new character array, based on the supplied mercury string.
the resulting array will be null-terminated, but is not guaranteed to only have null occur at the end.
returns nullptr on a memory allocation failure.

mercury_string* mercury_copystring(const mercury_string* const restrict str)

creates a new mercury_string which has the same data as the supplied.
if the supplied string is marked as constant, the pointer will be copied.
otherwise, this will create a new pointer and copy the data from the original
returns nullptr on a memory allocation failure.

mercury_string* mercury_mstrings_concat(const mercury_string* const str1, const mercury_string* const str2)

creates a new mercury_string whose data is the concatenation of both input strings, with the first arg being the first portion of the resulting string. returns nullptr on a memory allocation failure.

bool mercury_mstrings_append(mercury_string* const basestr, const mercury_string* const appstr)

modifies the first arg string with the second arg's string affixed to the end.
if the first arg is a constant string, a new pointer will be allocated to the string, and it will be unmarked as constant.
returns false on a memory allocation failure.

bool mercury_mstring_addchars(mercury_string* const M_CPP_restrict str, const char* const chars, mercury_int len=1)

modifies the first arg string with the supplied character array appended to it
if the first arg is a constant string, a new pointer will be allocated to the string, and it will be unmarked as constant.
returns false on a memory allocation failure.

mercury_string* mercury_mstring_substring(mercury_string* str, mercury_int start, mercury_int end)

creates a new string composed from the supplied string. the integer args are an offset from the start of the string (0 indexed)
may return a zero length (empty) string
returns nullptr on a memory allocation failure.

void mercury_mstring_delete(mercury_string* const restrict str)

frees the supplied mercury_string, regardless of reference count.
if the pointer is not marked as constant, it will be freed.

inline bool mercury_mstrings_equal(const mercury_string* const str1, const mercury_string* const str2)

returns a bool if the supplied mercury strings have the same data.

inline bool mercury_mstring_equal_cstring(const mercury_string* const mstr, const char* const cstr)

returns a bool if the supplied mercury string has the same data as the supplied null-terminated character array.

table functions

mercury_table* mercury_newtable()

creates a new, empty table object returns nullptr on a memory allocation failure.

mercury_int mercury_tablehaskey(const mercury_table* const table, const mercury_variable* const key)

searches a table for the supplied key. if found, returns the index in the subtable where it was found.
if not, returns -1.

bool mercury_getkey(const mercury_table* const table, mercury_variable* const key, mercury_variable* out)

sets the data at the variable pointer out to the value stored by the supplied key. if not found, returns false, and sets out to nil.

mercury_int mercury_setkey(mercury_table* const table, mercury_variable* const key, const mercury_variable* const value)

sets a key in the table, and returns the index in the subtable. on allocation failiure, returns -1.
both the supplied key and value will have their refrence count incremented and will be stored in the table.
the existing stored data will be unrefrenced, and position overwritten, potentially freeing the data.

bool mercury_tables_equal(const mercury_table* const table1, const mercury_table* const table2)

evaluates every key in a table against another table. if every value is equal, returns true. otherwise, false

bool mercury_table_get_cstring_keyvalue(const mercury_table* const table, const char* const key, mercury_variable* out)

sets the data at the variable pointer out to the value stored by the supplied key. if not found, returns false, and sets out to nil. Takes a null-terminated character array aas a key instead of a variable.

mercury_int mercury_table_set_cstring_keyvalue(mercury_table* const table, const char* const key, const mercury_variable* const value)

sets a key in the table, and returns the index in the subtable. on allocation failiure, returns -1.
both the value will have its refrence count incremented and will be stored in the table.
the existing stored data will be unrefrenced, and position overwritten, potentially freeing the data.
the supplied character array must point to a constant point in memory, and should not be freed, and be null terminated

mercury_int mercury_table_has_cstring_key(const mercury_table* const table, const char* const key)

searches a table for the supplied key. if found, returns the index in the subtable where it was found.
if not, returns -1.
the supplied character array must be null terminated

void mercury_prepare_table_for_state(mercury_table* table,mercury_state* M)

sets the values _G and _ENV given a state and its environment table.
additionally, sets the environmental flag of the table.

void mercury_cleartable(const mercury_table* const table)

goes through all stored variables in the stored table, and unrefrences, and possibly frees them, then removes them from storage.

void mercury_destroytable(mercury_table* const table)

frees the supplied table. goes through all stored variables, and unrefrences, and possibly frees them.

array functions

mercury_array* mercury_newarray()

creates a new array object.
returns nullptr on failiure.

bool mercury_setarray(mercury_array* const array, const mercury_variable* const var, const mercury_int pos)

sets the array's index to the provided value.
increases the supplied value's reference count.
if the index already stored a value, it will be dereferenced, replaced, and potentially freed.
on success, returns true.

void mercury_getarray(mercury_array* const array, const mercury_int pos, mercury_variable* out)

sets the data at the provided pointer to the value stored in the array at the index.
if the value is not present, nil is set instead.

mercury_int mercury_array_len(const mercury_array* const restrict arr)

returns the index of the array's value with the highest value.
if there are no values, -1 is returned instead.
ignores negative indexes.

void mercury_destroyarray(mercury_array* const restrict arr)

frees the provided array, and dereferences and potentially frees all stored values.

state functions

mercury_state* mercury_newstate(const mercury_state* const parent = nullptr)

creates a new state. if parent is provided, this will set the new state's parent to the provided.
returns nullptr on failure.

bool mercury_stepstate(mercury_state* const restrict M)

executes a single instruction of a state's bytecode.
returns true if there are more instructions to execute.

void mercury_clearstate(mercury_state* const restrict M, bool for_deletion=false)

clears a state into its initial state.
the second arg should not be used, as it is an internal designation

void mercury_destroystate(mercury_state* const restrict M)

frees a state and unreferences or frees all associated data.

void mercury_release_var(mercury_variable* const restrict var)

checks a variable's reference count, and frees the data if it is 0

void mercury_popstack(mercury_state* const restrict M, mercury_variable* out)

sets the data at the pointer out to the provided state's top stack element, and decreases the stack size.
if there is no element on the stack, out is set to nil instead.

void mercury_pullstack(mercury_state* const restrict M, mercury_variable* out)

sets the data at the pointer out to the provided state's bottom stack element, and decreases the stack size then shifts all elements back by 1.
if there is no element on the stack, out is set to nil instead.

void mercury_pushstack(mercury_state* const restrict M, mercury_variable* var)

adds the provided variable onto the top of the provided state's stack.
returns true if this occured successfuly, and false if not.

inline void mercury_discard_top_of_stack(mercury_state* const restrict M)

takes the top variable of the stack of the provided state, and removes it, potentially freeing it.

inline void mercury_peek_stack(const mercury_state* restrict M, mercury_variable* out)

sets the data at the pointer out to the variable on the top of the stack if it exists, nil if not.
does not change the stack size.

inline mercury_state* mercury_get_child_state(mercury_state* const M_CPP_restrict M)

returns a pointer to a state's child state, used for function calls.
creates the state if none exists.
returns nullptr on failure.

variable functions

mercury_string* mercury_tostring(const mercury_variable* const restrict var)

creates a new string that represents the supplied variable's value.
if the supplied variable is also a string, a new one is still created
returns nullptr on failure

bool mercury_checkbool(const mercury_variable* const restrict var)

interprets the supplied variable as a boolean, and returns the corresponding value.

mercury_int mercury_checkint(const mercury_variable* const restrict var)

interprets the supplied variable as an integer, and returns the corresponding value.

mercury_float mercury_checkfloat(const mercury_variable* const restrict var)

interprets the supplied variable as a floating-point number, and returns the corresponding value.

mercury_float mercury_checkpointer(const mercury_variable* const restrict var)

interprets the supplied variable as a pointer, and returns the corresponding value.
for non pointer types, nullptr is returned.

bool mercury_vars_equal(const mercury_variable* const var1, const mercury_variable* const var2)

evaluates if the two suppplied variables are equal, using mercury equality rules.

inline void mercury_clear_variable(mercury_variable* var)

sets the data at the pointer to nil

inline bool mercury_type_is_complex(const uint8_t type)

returns if the type is complex (referenced)

inline void mercury_increment_variable_refrence_count(const mercury_variable* const restrict var)

increments a variable's reference count

inline void mercury_decrement_variable_refrence_count(const mercury_variable* const restrict var)

decrements a variable's reference count

other functions

bool mercury_register_library(void* data, char* key, char* table, uint8_t type=M_TYPE_CFUNC)

adds data to mercury's global libraries list.
data is a pointer to the data
key is a null-terminated string
table is an optional null terminated string. if supplied with nullptr, will add the library to the table, otherwise, adds it to a sub-table whose key is the supplied string
type is the type of the library. supported types: int, float, bool, c function
returns false if the library failed to be added
not thread safe.

void mercury_populate_table_with_libs(mercury_table* T)

adds all libraries into the supplied table.

mercury_string* mercury_get_bytecode_debug(mercury_function* F)

generates a string representing a function's bytecode
annotates instructions and their bytecode parameters
returns nullptr on failiure

mercury_string* mercury_get_bytecode_rawbinary_debug(mercury_function* F)

generates a string representing a function's bytecode
annotates hex, char, (un)signed int, and opcodes
returns nullptr on failiure

void mercury_debugdumptable(mercury_table* tab, int level = 0)

generates a debug string of a supplied table, and sends it to stdout.
optional level arg is for internal use only.

void mercury_clone_function(mercury_function* in, mercury_function* out)

copies a function's data into a new function. the function object must already exist. on failure, the output function's instruction count will not be the same as the input's

void mercury_clear_function(mercury_function* in)

clears all data associated with a function pointer, but does not free the pointer.
