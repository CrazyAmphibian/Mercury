the state

the orcus runtime operates on 1 state at a time per thread. this state stores everything, from variables to bytecode.

struct orcus_state {
orcus_state* parentstate = nullptr;
orcus_state* masterstate = nullptr;
orcus_state* childstate = nullptr;

orcus_uint sizeofstack = 0;
orcus_variable* stack = nullptr;
orcus_uint allocatedstacksize = 0;
orcus_variable* registers = nullptr;
orcus_variable* constants = nullptr;
orcus_uint num_constants = 0;

orcus_uint programcounter = 0;
orcus_function* bytecode = nullptr;
uint32_t errorcode = 0;

orcus_table* enviroment = nullptr;
};

when a function is called, the childstate variable is used to store the state that the function will call in.
likewise, parentstate and masterstate store this state's host. though masterstate always refers to the top level element (including self), while parentstate is 1 level up (not including self)

the stack

being a stack-based language, the stack is very important, and has to be kept correct, or else the runtime will quickly fall apart.
the stack is simply an array of variables, with last in first out (LIFO) accessing by default.

orcus breaks down code into chunks called "statements", which are things such as a=5, or print("hello, world").
statements are always stack neutral, meaning that by the end of a statement, there should be no elements on the stack.
the runtime cannot see statements, as it's a concept that the compiler is designed around, but it's important to know nonetheless.

the stack array is dynamically reallocated when it needs to be, meaning that a stack overflow isn't possible in the orcus interpreter (though your system can still overflow if too many calls are nested).

void orcus_popstack(orcus_state* const ORCUS_CPP_restrict M, orcus_variable* out) {
 if (M->sizeofstack==0) {
  out->type = ORCUS_TYPE_NIL;
  out->data.i = 0;
  return;
 }
 M->sizeofstack--;
 *out= M->stack[M->sizeofstack];
}


bool orcus_pushstack(orcus_state* const ORCUS_CPP_restrict M, orcus_variable* const var) {
 if (!(M->allocatedstacksize > M->sizeofstack)) {
  void* nstackptr = realloc(M->stack, (M->sizeofstack + 1) * sizeof(orcus_variable));
  if (nstackptr == nullptr) return false;
  M->stack = (orcus_variable*)nstackptr;

  M->allocatedstacksize = M->sizeofstack + 1;
 }
 M->stack[M->sizeofstack] = *var;
 M->sizeofstack++;
 return true;
}

there are some safeguards in place to prevent an underflow reading invalid memory
