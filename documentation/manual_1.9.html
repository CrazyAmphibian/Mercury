1.8 Thread Library 1.9 Debug Library

Debug library contents are placed into the global debug table.
the debug library contains function to debug the mercury runtime, and will not be terribly useful for the average user.

CONSTANTS

Variable Type Value Desc

FUNCTIONS

void dumpstack ( )

logs information about the current state's stack to stdout, including how many variables are on the stack, what the variables' values are, and unallocated variables, as well as the allocated size of the stack array.

debug.dumpstack()


void dumpstate ( )

logs information about the current state structure to stdout, including how far the each state is into execution, the instruction address, and which state is the parent state recursively, until the master state is reached.

debug.dumpstate()


void dumpenv ( )

logs information about the environment to stdout, including associated state, and all values stored inside the environment table, and does so for each parent state until the master state.

debug.dumpenv()


void dumpconstants ( )

logs information about the state's constants to stdout, including how many constants the state has, and what the values of the constants are.

debug.dumpconstants()


void dumpbytecode ( [function function=_ENV] )

logs information about the provided function to stdout, including the number of instructions, and each opcode and additional information.
if no arg is given, instead uses the current state's bytecode.

debug.dumpbytecode(my_function)


void dumprawbytecode ( [function function=_ENV] )

logs information about the provided function to stdout, including the number of instructions, as well as a binary view of each, including raw data in the form of signed, unsigned, and char values.
if no arg is given, instead uses the current state's bytecode.

debug.dumprawbytecode(my_function)


void showrefs ( variable var )

Shows how many refs the value has, printed to stdout. If a non ref-counted variable is provided, it will display an invalid message, but not error.

debug.showrefs(i)


void dumpdebuginfo ( [function function=_ENV] )

Displays the given function's (or current state's) debug tokens to stdout.

debug.dumpdebuginfo(my_function)


string traceback ( )

returns a string containing the current traceback, including line number, column, and associated code

print("current location in code: "..debug.traceback())
