function responsibilities

a C function has to keep mind to the args_in and args_out variables. they are not requests, but demands. failing to modify the stack correctly will lead to corruption.
the only exception to this is throwing an error, where the state will be discarded anyways, and the stack won't matter.

so, keeping that in mind, let's go over how to make a C function add 10 to a number.

#include "mercury.hpp"

void add_10_to(mercury_state* const M_CPP_restrict M, const mercury_int args_in, const mercury_int args_out) {
  mercury_variable in;
  mercury_popstack(M,&in);
  in.data.i+=10;
  merucry_pushstack(M,&in);
}

if you're paying attention, you will notice 2 big issues. one is that we are completely ignoring the arg variables, the other is that we are not performing any type checking.

let's get to type checking later, for now let's just go over the arg variables.
fortunately, the error header comes with some functions to make this easy, so simply including it will make your life easier.

#include "mercury.hpp"
#include "mercury_error.hpp"

void add_10_to(mercury_state* const M_CPP_restrict M, const mercury_int args_in, const mercury_int args_out) {
  if(MERCURY_CFUNCTION_ENSURE_CORRECT_NUMBER_INPUT_ARGS(M,args_in,1)){
    return; //we want 1 arg minimum, and 1 arg maximum
  }

  mercury_variable in;
  mercury_popstack(M,&in);
  in.data.i+=10;
  if(args_out)merucry_pushstack(M,&in);

  MERCURY_CFUNCTION_ENSURE_CORRECT_NUMBER_OUTPUT_ARGS(M, args_out, 1); //because we are sending 1 arg
}

and now finally, let's add typechecking.

#include "mercury.hpp"
#include "mercury_error.hpp"

void add_10_to(mercury_state* const M_CPP_restrict M, const mercury_int args_in, const mercury_int args_out) {
  if(MERCURY_CFUNCTION_ENSURE_CORRECT_NUMBER_INPUT_ARGS(M,args_in,1)){
    return; //we want 1 arg minimum, and 1 arg maximum
  }

  mercury_variable in;
  mercury_popstack(M,&in);
  if(in.type!=M_TYPE_INT){
    mercury_raise_error_nonpointer(M,M_ERROR_WRONG_TYPE,in.type,M_TYPE_INT,1);
    return;
  }
  in.data.i+=10;
  if(args_out)merucry_pushstack(M,&in);

  MERCURY_CFUNCTION_ENSURE_CORRECT_NUMBER_OUTPUT_ARGS(M, args_out, 1); //because we are sending 1 arg
}
