FUNCTIONS

string sub (string str, int start, int end)

returns a sub string of a given string with a specified offset.
returns an empty string if the offsets are out of bounds.

string.sub("hello, world!",0,4) //returns "hello"


string reverse (string str)

returns a string which contains the reverse copy of the input string

string.reverse("hello") //returns "olleh"
string.reverse("racecar") //returns "racecar"


int|nil, int|nil find (string str, string match, [int start=0] )

attempts to find the string match inside of the provided string.
if found, returns the position in the string where it occurs, as well as where it ends.
otherwise, returns nil.

string.find("hello, world!","ll") //returns 2,3
string.find("hello, world!","ll",3) //returns nil,nil


string, int replace (string str, string match, string replacment, [int max_replacments=infinity] )

searches a string for all occurrences of a match, and replaces them with another string.
if the max replacements argument is provided, it can be used to limit the number of replacements done.
returns the new string, as well as how many replacements were done.

string.replace("hello, world!","l","t",2) //returns "hetto, world!", 2


int count (string str, string match)

returns the number of times the match is found in the string.

string.count("hello, world!","l") //returns 3


array toarray (string str)

returns an array representing the characters in a string.

string.toarray("hello") //returns [104,101,108,108,111]


string fromarray (array characters)

converts an array into a string. integers will have their lower 8 bits turned into a character.
all other types will be ignored, and replaced with the null character (\x00).

string.fromarray([104,101,108,108,111]) //returns "hello"


array separate (string str, string separator)

returns an array containing substrings of the input string, delimited by the separator. does not include the separator.
behavior is undefined if the seperator occurs at the start or end of the string, or if the seperator string is empty.

string.separate("hello.world",".") //returns "["hello","world"]"


string upper (string str)

takes a string and returns it with all uppercase characters.

string.upper("Hello, World!") //returns "HELLO, WORLD!"


string lower (string str)

takes a string and returns it with all lowercase characters.

string.lower("Hello, World!") //returns "hello, world!"


string format (string formatstring, variable ...)

takes a formatted string and adds in received values. works with similar syntax to C's printf.
formats start with a %, followed by a character depending on the value. this function will type coerce, and will never cause an error from the variadic arguments.

formats use the following format: %<type><flags><width>.<precision>

Mercury string patterns

string patterns follow the behavior of character specifier.
for example, %l matches any letter. to make it match more than one, add %+ or %- to the end of it (%l%+ or %l%-).
pattern sequences are always 2 characters wide, and start with a % to make them stand out and for clarity.

sequence matched characters
%% %
%n any number
%l any letter
%w any lowercase letter
%u any uppercase letter
%a any alphanumeric character
%s any symbol
%(SPACE) any whitespace character
%. any character. wildcard
%x any hexadecimal character (0-9, a-f, A-F)

sequence character specifier
%* 0 to infinity matches, greedy
%~ 0 to infinity matches
%+ 1 to infinity matches, greedy
%- 1 to infinity matches
%? 0 or 1 matches
%! 1 match (default behavior)
%/ 0 to infinity matches, greedy, inverted
%\ 0 to infinity matches, inverted
%# 1 to infinity matches, greedy, inverted
%@ 1 to infinity matches, inverted
%| 0 or 1 matches, inverted
%= 1 match, inverted

int|nil, int|nil pfind (string str, string match, [int start=0])

The same principal as string.find, but uses pattern matching on the match string.

string.pfind("result: 12.7","-%?%n%+.%?%n%*") //returns 8, 11


array pextract (string str, string match)

Takes a string and a pattern match, and returns all matches as an array. if none were found, an empty array will be returned.

string.pextract("result: 12.7","-%?%n%+.%?%n%*") //returns ["12.7"]


string, int preplace (string str, string match, [int max_replacments=infinity])

same function as string.replace, but works with pattern matching for finding occurrences.

string.preplace("hello, world!","l%+","t",1) //returns "heto, world!", 2


int pcount (string str, string match)

same as string.count, but uses pattern matches.

string.pcount("hello, world!","l%+") //returns 2


string escape (string string)

takes a string, and substitutes characters so that it could be interpreted properly as a string in mercury.
replaces quote mark (") and backslash (\)

string.escape("this is a \"cool\" test!") //returns "this is a \"cool\" test!"


string escape_url (string string)

takes a string, and substitutes characters so that it could be interpreted properly as a URL location. this does not create a URL adress, as many control characters will be escaped, such as ( / + or &

string.escape_url("awesome cool file/thing.odt") //returns "awesome%20cool%20file%2Fthing.odt"


string escape_c (string string)

takes a string, and substitutes characters that conform to the C escape sequence standards. does not escape hex characters, but will escape null.

string.escape_c("how\tinteresting!\0\\\nquite!") //returns "how\tinteresting!\0\\\nquite!"


string escape_html (string string)

takes a string, and substitutes characters so that the text may be used in HTML or XML without causing any special formatting changes.
escapes the following characters: < > & "

string.escape_html("<span class='thing'>woah!</span>") //returns "&lt;span class=&#39;thing&#39;&gt;woah!&lt;/span&gt;"


string copy (string string)

takes a string and creates a copy of it, as a distinct object with separate internal pointer and reference count. strings, unlike arrays or tables, will compare content to determine equality, so a copied string will be equal with the original.
useful for sending string values over to a thread where refcounting can result in races.

a="hello"
b=string.copy(a)
print(a,b,a==b) //outputs "hello" "hello" true
