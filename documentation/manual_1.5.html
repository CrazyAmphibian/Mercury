FUNCTIONS

file|nil open ( string path, string mode )

Mode can read can write if file doesn't exist if file exists
r, rb (read) yes no no file opened file opens
w, wb (write) no any position file created contents cleared
a, ab (append) no only at end of file file created file opens
r+, rb+ (extended read) yes any position no file opened file opens
w+, wb+ (extended write) yes any position file created contents cleared
a+, ab+ (extended append) yes only at end of file file created file opens

attempts to open a file at the specified path.
if succesful, returns a file, otherwise, returns nil.

mode specifies how the file is treated and what can be done.
Mode must be read, write, or append, extended optional.
The binary mode flag is automatically applied, so a file opened with "r" will open in "rb", and "w+" will open in "wb+"

io.open("test.txt","r") //returns a file if test.txt exists.


void close ( file file )

closes an open file. this is needed to allow other programs to modify the files.

a=io.open("test.txt","r")
io.close(a)


string read ( file file, [int number_bytes=all], [int offset=0] )

returns nil if a file was unable to be read. otherwise, returns the contents of the provided file.
If number_bytes is not provided or is nil, the entire contents of the file are read.
otherwise, number_bytes characters will attempt to be read. if offset is provided, then that byte offset is where reading will begin.
if not enough characters are available, the string returned will be smaller than number_bytes, potentially returning an empty string.

a=io.open("test.txt","r")
io.read(a) //returns the entire contents of the file.

offset=0 //reads until end of file.
while true do
str=io.readbytes(a,20,offset)
offset+=#str
if #str!=20 then break end //hit end of file
end


int write ( file file, string data, [int offset=end] )

attempts to write data to a file. returns how many characaters were written.
if offset is specified, the file will attempt (but may not, depending on file mode) to be written at that point.
otherwise, the characters will be added at the end of the file.
if offset is greater than the number of characters in the file, the characters between the write are defined per implementation, though is generally filled with NULL (0x00).

a=io.open("test.txt","w")
io.write(a,"hello!")


array getfiles ( string path )

returns an array of strings containing the files in a specified directory.
if the directory could not be located, returns an empty array instead.
If an empty string is given, returns the files in the current working directory.
Does not include implicit paths . or ..

a=io.getfiles("data") //might return something like ["test.txt","image.jpg","cool_song.mp3"]


array getdirs ( string path )

returns an array of strings containing the directories in a specified directory.
if the directory could not be located, returns an empty array instead.
If an empty string is given, returns the files in the current working directory.
Does not include implicit paths . or ..

a=io.getdirs("") //might return something like ["data","stuff"]


array lines ( file file )

returns an array of strings containing each line in a file. The file must be in read mode for any results to return. Does not include the newline characters themselves.

a=io.open("test.txt","r")
io.lines(a) //might return ["this","is","","a test"]


void post ( string text )

writes a string to stdout.
unlike print, the input must be a string. additionally, this function is not variadic, and will not add any terminating newlines.

io.post("hello!\n")


string prompt ( )

awaits input from stdin. input will be accepted after the user hits enter. returns a string containing the text, minus newlines.

a=io.prompt()


string input ( )

awaits a single keypress from stdin. does not require pressing enter. returns the input as a single character.
use caution if using this in a loop, as the control+C break sequence will not be captured by the program, and instead be sent as raw input.
instead. you should check for the sequence 0x03

a=io.input()


bool remove ( string path )

attempts to remove a file with the given path.
if successful, or the file doesn't exist, returns true, otherwise false.

io.remove("test.txt")


bool removedir ( string path )

attempts to remove a directory with the given name/path.
if successful, or the directory doesn't exist, returns true, otherwise false.
can only remove empty directories.

io.removedir("data")


bool createdir ( string path )

attempts to create a directory with the given name/path.
if successful, or the directory already exists, returns true, otherwise false.

io.createdir("data")


string|nil serialize ( serializable variable )

converts a serializable variable into a string that can be read back later with deserialize.
this is both faster and more space efficient than trying to recompile variables as code.
ignores non-serializable types, and returns nil on faliure. does not support and ignores self-referential data.

io.write(output_file,io.serialize(data))


variable|nil deserialize ( string serialized )

converts a serialized string back into data.
returns nil on failiure.

data=io.deserialize(io.read(output_file))


string getworkingdir ( )

returns the executable's working directory, usually where the program was executed from, and not nescicarily where the executable is.
returns the path using the system's path separator.
This is the path OS commands will execute in, and this is where filesystem modification will be relative to if no absolute position is given.

f=io.open(io.getworkingdir().."/file.txt","r")


string getexecutabledir ( )

returns the directory the executable is in.
returns the path using the system's path separator.

f=io.open(io.getexecutabledir().."/file.txt","r")


int size ( file file )

returns the size of a file in bytes.
if the file has read access, this will be the size of the entire file.
if the file does not have read access, but has write access, this is instead the number of bytes written to the file.
otherwise, returns 0.

io.read(f,io.size(f)\2) //reads the first half of the file.
io.read(f,nil,io.size(f)\2) //then, the second half
