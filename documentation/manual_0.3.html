keywords

mercury has 18 reserved keywords. these have special treatment from the compiler, and cannot be directly used as variable names. keywords are case sensitive.

  • if
  • do
  • nil
  • inf
  • end
  • true
  • then
  • else
  • goto
  • break
  • while
  • false
  • local
  • global
  • elseif
  • return
  • continue
  • function

static variables

static variables represent a constant data, and can be used for assignment or comparison

  • nil
    • represents the nil datatype
  • inf
    • represents infinity as a float
  • true
    • represents boolean true
  • false
    • represents boolean false

scope specifiers

these keywords modify how the compiler assigns and retrieves variables to fine tune scope

  • global
    • tells the compiler the variable should belong to the top-level state
  • local
    • tells the compiler the variable should belong to the bottom-most state

flow control

these keywords determine how a program behaves, and are written in a specific way

  • end
    • universal delimiter for statment bodies
  • if then else elseif
    • used in if statements
  • while do
    • used in while loops
  • break continue
    • modifies loop execution
  • goto
    • unconditional jump to a specific point in code.
  • return
    • stops execution of the current state, and pushes return variables upwards
  • function
    • starts a function body
