if statements

if statements allow for conditional running of code segments. the basic if statement is quite simple.

if condition then
 //code to run
end

the else keyword can be used in conjunction, and runs code if the condition is false. only one else can be used in a block.

if a>5 then
 print("a is more than 5")
else
 print("a is not more than 5")
end

the final piece is the elseif keyword, which acts as a secondary check. you can use as many elseif blocks in a statment as you want, however elseif must come before else.

if a>0 then
 print("a is positive")
elseif a<0 then
 print("a is negative")
else
 print("a is 0")
end

while loops

while loops continually execute their body as long as the condition is true

while condition do
 //code to run
end

break can be used to jump out of the loop prematurely. in the case of nested loops, the innermost loop is affected only.

a=10
while a do
 a--
 if should_exit() then break end
end

continue can be used to skip the current iteration of the loop. as the same with break, only the innermost loop is affected.

a=10
while a do
 a--
 if a%2==0 then continue end
 print(a)
end

functions

functions exist to segment portions of code, and to make re-use easier. functions are defined by the function keyword, followed by parenthesis containing args. afterwards, the code body, then end keyword.

unlike other languages, mercury functions are not given a name, rather they are directly assigned to variables. this means that technically speaking, every function is a lambda/anonymous. return can be used to push values back.

add_2_numbers=function(a,b)
 return a+b
end

sum = add_2_numbers(5,10) //15

if a function is provided more args than it requests, the additional args will be discarded

sum = add_2_numbers(5,10,50) //still 15, the 50 is dropped when calling

when less args are given, any missing will be filled in with nil

sum = add_2_numbers(5) //throws an error, because this will attempt to add nil to 5.

variables in functions are, by default, local to that function, and cannot be accessed outside of it. functions can still see and change values outside of their body, as long as the names do not overlap

add_2_numbers(1,2)
print(a,b) //nil nil, because a and b are local to the function

a=10
add_2_numbers(1,2) //a is still 10, as the function makes its own version of the variable a when it is called

add_a_number=function(b)
 return a+b
end
add_a_number(5) // returns 15, as the function searches outwards to find a, which is 10.

functions can return multiple values, with similar rules to input args regarding too many/too few.

sum,c=add_2_numbers(1,2)
print(sum,c) //3 nil

add_numbers=function(a,b)
 return a+b,a,b
end

sum,first,second = add_numbers(10,20)// output: 30 10 20
sum = add_numbers(17,3) //output: 20

goto

goto represents an unconditional jump to a line of code that can be earlier or later than the jump.

goto skip
a=50
skip:
print(a) //nil, because a's defenition was jumped over

goto can jump into or out of if statments, or while loops.

if a<=0 then
 a=10
 label:
 set=true
end

while a do
 a--
 if a%3==1 then goto label end
end

goto cannot jump into or out of a function body. trying to do so will result in nothing happening, as the compiler cannot see the label, and never sets the goto jump to any position.

stuff=function()
 label:
 goto label2: //invalid. the only visible label is label
end

goto label: //invalid. the only visible label is label2
label2:
