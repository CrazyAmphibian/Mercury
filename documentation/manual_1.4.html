FUNCTIONS

int time ( )

returns an integer of the current time in seconds since the epoch (unix time)

os.time() //result varies when program is executed


float clock ( )

returns a float of how long the program has been running

os.clock()


string execute (string command )

executes a string as if it were a shell command.
input is platform-dependent.
This function uses C's popen function, meaning command output is piped into a string. Some commands may not function as expected.

os.execute("curl www.test-site.com") //returns a web request result


int call (string command )

executes a string as if it were a shell command.
input is platform-dependent.
This function uses C's system function, meaning the command runs in stdout/stdin, and this returns the response code of the command.

os.call("curl www.test-site.com") //returns 0


table get_date (int epoch_time )

Returns a table containing data about the date given an epoch timestep.
The following data is given:

Key value
seconds The number of seconds in the time as an integer from 0 to 60
minutes The number of minutes in the time as an integer from 0 to 60
hours The number of hours in the time as an integer from 0 to 23
hours12 The number of hours in the time as an integer from 1 to 12
ispm A boolean if a 12 hour clock would read the time as PM, to be used with hours12
year The year of the time, as an integer
month The month of the time, as an integer from 1 to 12
dayofweek The day of the week, as an integer from 0 to 6, with 0 representing Sunday.
dayofmonth The day of the month, as an integer from 1 to 31.
dayofyear The day of the year, as an integer from 1 to 366.

print("the year is " .. os.get_date(os.time()).year)


int get_time (table date )

Returns an integer as epoch time, based upon the date table provided.
returns -1 on an error.
Behavior before the epoch (January 1st, 1970) is system dependent, and may fail.

The function uses the following keys, though does have fallback values:

Key value
seconds The number of seconds in the time as an integer from 0 to 60. Default: 0
minutes The number of minutes in the time as an integer from 0 to 60. Default: 0
hours The number of hours in the time as an integer from 0 to 23. Default: 0
year The year of the time, as an integer. Default: 1900
month The month of the time, as an integer from 1 to 12. Default: 1
dayofmonth The day of the month, as an integer from 1 to 31. Default: 1
daylightsavings If daylight savings is active. 0=no, 1=yes, -1=auto detect. Default: 0

print("the time during january 3rd, 2143 is "..get_time({"year"=2143,"month"=1,"dayofmonth"=3}))


void exit ( [int exitcode=0] )

Closes the executable immediately, and returns an exit code to the operating system.
By default this is 0. on 64 bit systems, integers will be downgraded to 32 bit before being passed.
If a non-integer type is provided, exits with code 0.

if something_wrong then
os.exit(1)
end
