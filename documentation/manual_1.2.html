FUNCTIONS

number min (number ...)

returns the lowest number provided.
returns infinity if no numbers are provided.
ignores non-number values.

math.min(12.1,1.3,4) //returns 1.3
math.min(-7,1,0.4) //returns -7


number max (number ...)

returns the highest number provided.
returns negative infinity if no numbers are provided.
ignores non-number values.

math.min(12.1,1.3,4) //returns 12.1
math.min(-7,1,0.4) //returns 1


int floor (number number)

returns the next lowest integer that can represent the supplied value.

math.floor(12.1) //returns 12
math.floor(-3.1) //returns -4


int ceil (number number)

returns the next highest integer that can represent the supplied value.

math.floor(12.1) //returns 13
math.floor(-3.1) //returns -3


float radians (number angle)

converts an angle from degrees to radians.

math.radians(90.0) //returns 1.57...


float degrees (number angle)

converts an angle from radians to degrees.

math.radians(math.pi/2) //returns 90.0


float log (number number, [number base=math.e])

returns the logarithm of a supplied number, given an optional base.
If no base is given, the natural logarithm (e) is used.
may return nan or infinity on invalid numbers.

math.log(64,2.0) //returns 6.0
math.log(105) //returns 2.02...


number abs (number number)

returns the absolute value of a number

math.abs(-64) //returns 64
math.abs(-3.7) //returns 3.7


float sin (number angle)

float cos (number angle)

float tan (number angle)

returns the sine, cosine, or tangent of an angle, in radians.

math.sin(1.2) //returns 0.93...
math.cos(1.2) //returns 0.36...
math.tan(1.2) //returns 2.57...


float asin (number angle)

float acos (number angle)

float atan (number angle)

returns the arcsine, arccosine, or arctangent of a given length ratio as a float, and returns the angle in radians.
may return nan with invalid inputs

math.asin(0.93) //returns 1.2...
math.acos(0.36) //returns 1.2...
math.atan(2.57) //returns 1.2...


float atan2 (number x, number y)

returns a radian angle to point to the relative coordinates x,y
handles edge cases, and will always return a valid angle when given ordinary numbers

math.atan2(10,10) //returns 0.78...


int randomseed ([int seed])

if provided, sets the random number generator's seed.
only the lowest 32 bits of the seed will be read.
returns the current seed.

this function is not thread safe.

math.randomseed(os.time())


float random ([number minimum, number maximum])

returns a random number as a float.
if no arguments are provided, the result will be between 0 and 1.
otherwise, it will be between the minimum and maximum
the results of a random call are slightly different between 32 and 64 bit systems, but are generally equal out to 7 digits between 0 and 1.

this function is not thread safe.

math.random(1,5) //may return 4.671...


int randomint ([int minimum, int maximum])

returns a random number as an int.
the random number will be between minimum and maximum, inclusive of the high and low bounds.

this function is not thread safe.

math.randomint(1,5) //may return 4


bool isnan (float number)

returns a bool if the supplied float is a non-number value.
this includes all types of NaN, as well as infinity.
If a non-float value is supplied, it will always return false.

math.isnan(0/0) //returns true
math.isnan(10/0) //returns true
math.isnan(0/10) //returns false


number amax (array values)

returns the highest value in an array, or negative infinity if no values were found.
skips non-number values.

math.amax([1,2,3,4,5]) // 5
math.amax([]) // -inf
math.amax(["hello",5,"test",1,-4,10.9]) // 10.9


number amin (array values)

returns the lowest value in an array, or infinity if no values were found.
skips non-number values.

math.amax([1,2,3,4,5]) // 1
math.amax([]) // inf
math.amax(["hello",5,"test",1,-4,10.9]) // -4


number mean (number ...)

returns the mean (average) of all numbers given.
if no numbers are provided, returns NaN

math.mean(12.1,1.3,4) //returns 5.8
math.mean(-7,1,0.4) //returns -1.8666...


number amin (array values)

returns the mean (average) of all values array, or NaN if no values were found.
skips non-number values.

math.amax([1,2,3,4,5]) // 3
math.amax([]) // nan
math.amax(["hello",5,"test",1,-4,10.9]) // 3.225
