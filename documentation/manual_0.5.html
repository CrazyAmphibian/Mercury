arithmetic operators

these operators can take any number type, and return a number type. in general, if one arg is a float, a float will be returned. if both args are ints, then an int will be returned.

symbol operation type comments
+ addition binary
- subtraction binary
- negation unary in general putting - before a variable will make it negation
* multiplication binary
/ division binary always returns a float
^ exponentiation binary always returns a float
% modulo binary
\ integer division binary always returns an int
++ increment unary must be used on a named variable as a standalone statement
-- decrement unary must be used on a named variable as a standalone statement

bitwise operators

these operators can take any number type, return a number type of the left-hand (first) arg type.

symbol operation type comments
& bitwise and binary
| bitwise or binary
~ bitwise xor binary
! bitwise not unary not to be confused with logical not

comparative operators

these operators can take any number type, and return a boolean.

symbol operation type comments
> greater than binary
< less than binary
>= greater than or equal binary
<= less than or equal binary
== equal to binary can take any type
!= not equal to binary can take any type

boolean operators

these operators can take any type and return a value that is able to be evaluated as a boolean value.
boolean operators do not perform short circuit logic.

symbol operation type comments
&& logical and binary if true, returns the right-hand (second) arg, otherwise false. cannot be used for self-modification.
|| logical or binary if true, returns the left-hand (first) arg, otherwise returns the right hand (second) arg. cannot be used for self-modification.
~~ logical xor binary if true, returns the true arg, otherwise returns false. cannot be used for self-modification.
!! logical not unary always returns a boolean type.

structure operators

these operators are usable on structures, and cannot be used for self-modification.

symbol operation type comments
# length
count		 unary arrays: returns the highest index, plus one, or 0 if no elements.
strings: returns number of characters
tables: returns number of stored elements (may include nil)
[ ] retrieve
get		 binary also used for assignment. cannot be used for self-modification.

misc operators

these do not fall into one of the other categories

symbol operation type comments
.. concatenate binary can take any type, forces string conversion. always returns a string.
( ) call variadic also used for nesting sub-statements.

self-modification

except where noted, all binary operators can use self-modify syntax. this not only looks cleaner, but is slightly faster, as it can skip re-attaining the variable's location.
this is done by putting your operator symbol after a variable, then adding an equals sign to it.
self-modification treats the existing variable as the left-hand side arg.

a=10
a=a+5
a+=5 //does the same code as above.
print(a) //20

a\=4 //same as a=a\4
print(a) //5
