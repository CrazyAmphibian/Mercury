1.0 Libraries 1.1 Standard Library

Like any language, Mercury has a set of libraries to extend its functionality. These libraries are categorized by function and scope

Library Purpose
Standard Basic functions for debugging, data traversal, and extending the language
Math Mathematical constants and utility functions
String String manipulation
OS Interfacing with the system, or checking system info
IO Filesystem reading and writing
Array Array manipulation
Table Table manipulation
Thread Starting and communicating with threads
Debug Debugging

This chapter will go over every function and constant provided in each library in breif.
