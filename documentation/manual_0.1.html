Comments

Comments in mercury come in 2 varieties, single line, and multi-line

Single line comments span until the line ends

print("hello, world!") //this code does stuff

Multi-line comments span until the delimiting characters.

/*
this no longer does anything

print("hello, world!")
*/

If a single and multi-line comment overlap, the fir comment style takes priority

//commented! /*
also commented!
*/

// /* */ still commented here

/* comment! // still a comment! */ print("this code still runs.")

Order of Operations

Mercury splits operations into the following groups, executed into this order:

  1. variable retrieval
  2. variable indexing
  3. function call
  4. unary operation
  5. binary operation
  6. variable assignment

binary operations are applied in left-to-right order, with no regard for conventional math operations order.
unary operations are applied in right-to-left order
both indexing and function calls are done left-to-right, with each calling its own sub-order of operations for each index/arg

for example:

b = #a + 1 / 3

the following happens:

first, the variable a is retrieved
next, the length operator (#) is applied to it
then, the number 1 is added to the result
then, the result is divided by 3
finally, the variable b is assigned the result.

another example:

a = 5 + 3 / 4    //a is 2.0
a = 3 / 4 + 5    //a is 5.75
a = 5 + (3 / 4)  //a is 5.75
